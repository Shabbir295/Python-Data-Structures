# 🐍 Python Data Structures

Welcome to my **Python Data Structures** repository.

This repository contains my learning notes, examples, practice programs, and Jupyter Notebooks covering important Python data structures.

## 📚 Data Structures Covered

### 📋 1. Lists

Lists are ordered and mutable collections used to store multiple values.

Topics covered:

* Creating Lists
* Data Types in Lists
* Indexing
* Negative Indexing
* Slicing
* Updating Items
* Adding Items
* Removing Items
* Looping Through Lists
* Nested Lists
* List Methods
* Useful Built-in Functions

Important methods:

```text
append()
extend()
insert()
remove()
pop()
clear()
index()
count()
sort()
reverse()
copy()
```
